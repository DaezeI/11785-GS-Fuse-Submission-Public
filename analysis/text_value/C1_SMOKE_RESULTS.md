No confidence interval is reported because there are only eight distinct
dates. In this tiny run, correct and shuffled articles have almost identical
errors. The checkpoint learned from 16 events, so this cannot resolve whether
article text helps a properly trained model. The model's smoke validation and
test losses likewise are execution checks only.

## Remaining scientific gate

The manifest does not include per-article release timestamps, particularly
for categories 7–12, which account for most events. The price CSV timezone
and whether timestamps mark bar starts or ends are unresolved. Resolve these
before claiming publication-time-safe text availability. Then plan a full C1
baseline checkpoint and evaluate it with the same paired protocol and enough
distinct dates for uncertainty estimates. The 16-event checkpoint must not be
used as that baseline.
