# Midterm report (Overleaf / NeurIPS 2019)

This folder is a self-contained Overleaf project. It uses the course template
(`neurips_2019.sty`, `\usepackage[final]{neurips_2019}`).

## Upload to Overleaf

1. New project → Upload project, or drag these files into an empty Overleaf project:
   - `main.tex`
   - `neurips_2019.sty`
   - `figures/training_curves.png`
   - `figures/interpretability.png`
2. Set the compiler to **pdfLaTeX** and the main document to `main.tex`.
3. Compile. Authors are still placeholders (`[Member 1]` …); fill them in before submission.

If you prefer to paste rather than upload: paste `main.tex` into Overleaf's editor,
then upload `neurips_2019.sty` and the two PNGs into a `figures/` folder at the
project root.

Do **not** use the IEEE `IEEEtran` PDF in `../midterm_report.pdf`; the course asks
for this NeurIPS 2019 style.
